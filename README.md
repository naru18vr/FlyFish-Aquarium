# FlyFish Aquarium

## 小さな遊びノート

水槽右上の「遊びノート」から、5つの遊びを開けます。水槽モードでも利用できます。

- **なかよし**：なでるモードで魚をつつくと仲良し度＋2（動いている水槽の時間で2秒に1回）。実際に餌を食べた魚も＋1（5秒に1回）。8・24・60で仲良しの段階が上がり、貝殻をもらえます。名前は16文字まで。顔なじみの魚を呼ぶと、10秒ほど人工的な感覚入力を与えて近くへ誘います。餌・敵・壁の判断は引き続き優先します。
- **音あそび**：3つのフレーズをお手本の順に演奏。光る輪の魚、または同じ音階の魚をつついて進みます。矢印キーとEnter / Spaceでも演奏できます。時間制限なし。最初の完成で貝殻＋5、魚たちがくるりと踊ります。再演奏でも踊りますが、貝殻は重複して増えません。
- **図鑑**：5種の魚と、食事・群れ・敵からの逃避・餌場への集合・ゆっくりした泳ぎ・仲良し・呼び寄せ・演奏・模様替えの14項目。実際の状態から観察して記録し、新しい発見で貝殻＋4。群れとゆっくりした泳ぎは3秒続くと発見します。
- **模様替え**：最初に貝殻8個。夕焼け・星夜の背景、桃色の海藻、すみれ色の岩、真珠の貝・小さなアーチ・おほしさまを交換できます。飾りは表示切り替えと左・中央・右への移動に対応。一度交換したものは繰り返し使えます。飾りは魚の衝突判定を変えません。
- **訪問者**：最初は約45秒、その後は約150秒ごとにカニ・宝箱が来ます。18時〜6時の端末の時刻では光る魚も登場。90秒滞在し、絵か「会いにいく」ボタンをタップすると貝殻と出会いの記録が増えます。取り逃しても罰則はありません。一時停止と背景タブの時間は進行に加算しません。

ノートは `flyfish-play-v1` に保存します。魚の番号は安定した水槽の枠として扱い、魚数を戻した時や水槽をリセットした時も名前・仲良し度を引き継ぎます。設定の初期化はノートを消しません。保存がブロックされた環境でも、そのページを開いている間は遊べます。フレーズのお手本はユーザー操作で音をオンにし、既存の音量・消音設定を使います。通常の魚クリックは従来の刺激で、なでるモードかフレーズ中は驚かせません。

`src/game.ts` は進行・報酬・保存値検証、`src/game-ui.ts` と `src/game.css` は遊びノートと水槽内の操作を担当します。訪問者・飾り・ハートのドット絵は既存のPixiJS描画に追加し、外部画像や新しい依存関係は使っていません。

CIのブラウザーテストはソフトウェア描画の負荷を抑えるため1並列で実行します。曲・音色・連続入力・全画面の操作は短いケースに分けて検証。曲の操作確認ではスケジューラーの進行と音高を検証し、公開後のテストでは生成音をMediaRecorderで記録・デコードして、BGMと効果音が実際に出力されたことを測ります。一瞬の音量値だけで再生の成功・失敗を判定しません。

小さな水槽、大きな好奇心。ショウジョウバエの公開コネクトーム由来の神経回路とプログラムAIをブレンドし、かわいいドット絵の魚のふるまいを観察する静的Webアプリです。

公開サイト：**https://naru18vr.github.io/FlyFish-Aquarium/**

## 遊び方

- 空いている場所をクリック / タップ：水面から餌を落とす。
- 魚をクリック / タップ：左右の刺激を感覚入力へ渡す。近くの魚にも弱く伝わります。
- Shift＋魚クリック、または「脳をのぞく」を選んで魚をタップ：個体情報・感覚・運動・脳活動を見る。
- キーボード：Tabで水槽へ移動し、矢印キーで魚を選択、Enter / Spaceで刺激、未選択なら餌、Escapeで選択解除。
- 魚の種類：キンギョ・テトラ・エンゼルフィッシュ・フグ・クマノミ。形や泳ぐ速さ・旋回に違いがあり、5種類を混ぜるか1種類にそろえられます。
- 敵の種類：サメ（追跡）、クラゲ（漂流）、イカ（短いダッシュ）。3種類を混ぜるか1種類にそろえられます。「3種類をいっしょに」で敵を3匹以上にし、すべての種類を登場させられます。
- 右上の設定：魚数12〜40（30匹可）、Fly Brain比率0〜100%、敵0〜8、餌場0〜6を即時変更。
- Fly Brain / Hybrid / Programプリセット：90 / 50 / 0%。初回起動は指定どおり70%。
- 詳細設定：個体差、クリック反応、刺激・伝播強度、海藻・岩・泡、Brain Quality、開発ログ。
- 「水槽モード」または水槽右上の拡大ボタン：画面いっぱいに水槽を表示。縦画面や画面の回転に合わせて配置が変わり、魚の状態は保たれます。下のボタンで餌・個体情報・一時停止を操作し、「戻る」またはEscapeで通常画面へ戻ります。対応ブラウザーでは拡大ボタンでブラウザーも全画面にできます。
- [水槽モードを直接開く](https://naru18vr.github.io/FlyFish-Aquarium/?tank)。
- 水槽右上：一時停止・再開、リセット。設定はこのブラウザーに保存されます。

初期状態は魚24匹、敵1匹、餌場2個、Fly Brain70% / Program30%、Medium10Hz。魚と敵の種類は初期値で混合。敵1匹ではサメが登場し、3匹以上で全種類が登場します。敵は魚を殺しません。餌場は自動で餌を出すため、操作しなくても魚たちが泳ぎ、集まり、逃げます。

## レトロな音で遊ぶ

設定の「音であそぼう。」で音をオンにしてください。初回は無音で始まります。

- オリジナルBGM9曲：ひだまりピコピコ / 泡のオルゴール / おさんぽアーケード / おひるねピクニック / 月あかりの子守唄 / サンゴのダンス / 雨つぶのメロディ / 星くずパレード / 夕暮れの港。
- つつく音8種類：ピコピコ / ぽろん / きらきら / ぷくぷく / ちりん / ぴょこん / ころころ / こだま。魚ごとに10種類の音の高さを割り当て、選んだBGMに合うペンタトニック音階で演奏できます。
- BGMと効果音は個別にオン・オフ。音量調整・音色の試聴・設定保存に対応。
- 「BGMのリズムに合わせる」は近い拍へ合わせます。タップを長く待たせないよう補正は最大75ms。オフにすると即時に演奏できます。
- 水槽モードでもスピーカーボタンで音を切り替え可能。魚をつつくと音符が浮かびます。
- 一時停止中はBGMが止まり、魚をつつく音は使えます。別タブや画面ロック中は音を止めます。再読み込み後はボタンで音を再開してください。

Web Audioによる独自の作曲・合成音を使用し、外部の音楽ファイルは取得しません。音はユーザー操作から開始します（[Web Audioの再生開始について](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)）。

## GitHub Pages

1. リポジトリの **Settings → Pages → Build and deployment → Source → GitHub Actions** を選択。
2. `main`へのpush、または **Actions → Deploy FlyFish Aquarium to GitHub Pages → Run workflow** で公開。
3. 公開先： https://naru18vr.github.io/FlyFish-Aquarium/

`.github/workflows/pages.yml`が型チェック、単体テスト、ビルド、PC・モバイル操作の検証を実行し、成功した場合にPagesへ配信します。公開後は実際の公開URLでもWorker起動・餌・個体情報を検証し、`published-browser-checks` artifactに画面と結果を保存します。初回のPages有効化はリポジトリ管理設定が必要な場合があります。`.github/workflows/checks.yml`は別途、デスクトップ・モバイルのブラウザー操作を検証し、スクリーンショットとレポートを`browser-checks` artifactとして保存します。

Viteの`base: './'`により、プロジェクト名以下のURLでもWorkerとJSONを正しく取得します。バックエンド・アカウント・実行時の研究APIは不要です。Google Fontsは任意の表示用通信で、取得できなくてもシステムフォントで動作します。

## 「ハエ脳」の意味

このアプリは **FlyWire FAFB v630** の実測接続データを使います。データは[原研究のMurthy Lab公開リポジトリ](https://github.com/murthylab/flywire-network-analysis/tree/ee4944c03429edf857a6b10bcf98bea7dcef35b8/v630_data)から取得し、中央複合体（CX）と一部の下行ニューロン（DNa01 / DNa02）を抽出しました。最大768ニューロン・25,274接続で、架空の接続を生成していません。

**全脳シミュレーションや、検証されたハエ／魚の行動再現ではありません。** 感覚入力をどのニューロンへ投射するか、活動を魚の左右旋回・加速・制動へどう読み出すかは人工的なアダプターです。切り出された回路、正規化した重み、簡略化した伝達物質の符号、軽量LIFモデルを使います。比率を変えて観察できる教育・創作向けのモデルです。

接続構造は全魚で共有しますが、膜電位、不応期、発火、活動の履歴、乱数状態は魚ごとに独立です。神経活動はメインスレッドでは計算しません。

| 品質 | ニューロン | Worker更新 |
|---|---:|---:|
| Low | 256 | 5Hz |
| Medium | 512 | 10Hz |
| High | 768 | 15Hz |

各更新は5msのLIFサブステップで進み、どの品質でも同じ実時間をシミュレーションします。負荷が高い場合はLowへ切り替えてください。描画はrequestAnimationFrame、物理は60Hzの固定刻み（描画が遅い場合も最大100ms分を補います）、通常AIは20Hz、神経入力は魚をまとめてWorkerへ送信し、応答待ち中の重複送信を避けます。Spatial Gridで餌・仲間・敵の近傍探索を行います。目標は60fpsですが、端末・ブラウザー・品質設定によって変わります。

## 構成

```text
src/main.ts              初期化、設定保存、Worker通信、更新時計
src/simulation.ts        魚、敵、餌、餌場、感覚、Program AI
src/audio.ts             オリジナルBGM、効果音、拍への補正、音量・停止管理
src/species.ts           種類、運動パラメーター、オリジナルドット絵パターン
src/math.ts              Spatial Grid、数値制限、衝突安全層
src/renderer.ts          PixiJS描画、オリジナルドット絵
src/ui.ts / style.css    設定、操作ガイド、個体情報、データ出典
src/brain/model.ts       LIF、独立した個体の脳状態、人工アダプター
src/brain/worker.ts      バッチ神経計算（Worker内のみ）
public/data/             静的な実データ由来コネクトーム
scripts/                 再現可能なデータ抽出
tests/                   神経応答、衝突、餌、操作、モバイル検証
```

100% Fly Brain時にも、数値制限、水槽境界、岩からの押し出し、移動量の制限を常時適用します。クリック処理は魚の位置を直接変えず、左右のstartle入力を増やします。接続データの形式も検証します。取得が20秒以上停止した場合やWorkerが15秒以上応答しない場合も、Programへ切り替え、再読み込みまで神経比率を上げられなくします。

品質変更・リセット前の古いWorker応答は採用しません。餌場は岩を避けて配置し、一時停止中の描画は5Hzに抑えます。

開発時はURLに`?debug`を付けると読み取り用診断ハンドル`window.__aquarium`を公開します。個体パネルのログは設定からオンにできます。

## データを再抽出する

Python 3の標準ライブラリのみで再現できます。元データは約30MB、最初の実行のみダウンロードします。

```sh
python scripts/extract_connectome.py --cache .cache/flywire
```

元データのGit commitとSHA-256、抽出規則をJSON内に記録しています。Root IDはJavaScriptの整数精度で壊さないよう文字列のまま保存します。品質ごとの回路は同じ選定順の256 / 512 / 768ニューロンを使う誘導部分グラフです。

### 遊びの入口と操作

水槽右上の「遊びノート」を開くと、5つの遊びを説明付きで選べます。「魚となかよし」→「水槽でなでる」でなでるモードをオンにして水槽へ戻ります。名前の保存結果、呼び寄せに必要な仲良し度、交換に不足している貝殻を画面に表示します。水槽モードのボタンには日本語ラベルがあり、休止・再開や音のオン・オフの状態も見えます。

### マウスと一緒に泳ぐ

遊びノートの「なかよし」→「一緒に泳ぐ」でマウス追従をオンにします。近く320の範囲の魚が反応し、仲良し度8以上では600まで届きます。タッチ画面は指でなぞる間だけ反応します。餌・敵・岩を優先し、びっくりした魚、脳を見る操作中、音あそび中は追従を休止。水槽を離れる、画面を隠す、表示を切り替えると追従先を解除します。オン・オフは保存しますがカーソル位置は保存しません。神経モデルへの人工的な感覚刺激です。

### おるすばんと放置の遊び

- 「おるすばん」で貝殻ひろい、20分で咲く海藻ガーデン、1時間・3時間の探検、卵と稚魚、留守中の日記、水槽Lv.1〜4を利用できます。
- 画面を閉じた時間は端末時計で計算し、1回の空白は最大8時間。貝殻は5分に1個、200個まで。開花・帰還・訪問者の報酬は期限なく受け取れます。魚が死んだり、離れていたことで進行を失ったりしません。
- 卵は20分後に初登場、以降は2時間間隔。30分で孵化し、観賞用の稚魚12匹までが別の群れで泳ぎます。成魚の神経計算・魚数設定とは別です。
- 水槽の成長には時間と図鑑の発見の両方が必要。夕焼け・星夜・アーチ・星の飾り、海藻の種類、貝の妖精、新しい探検を解放。解放した飾りは模様替えから無料で適用します。
- 仲良し度8から探検可能。探検中の魚は描画・食事・接触・追跡から外れ、帰還で戻ります。探検中の魚だけが担当する音は、その魚が戻るか魚数を増やすまで音あそびで選べません。
- 留守番の自動ごはんは45秒ごと（動いている水槽のみ）。手動の餌で実際に食事すると仲良し度＋2、自動の餌は＋1。どちらも同じ魚への5秒の間隔制限があります。
- 放置の時計は物理の一時停止とは独立。神経シミュレーションを閉じたページで動かすのではなく、時間差で育成と物語の日記を計算します。端末時計の巻き戻しは経過ゼロとして扱い、同じ時計区間を再計算しません。
- 放置保存キーは `flyfish-idle-v1`。報酬を先に保存してから遊びノート側に受領IDを記録し、再読み込み・受取途中の中断でも同じ報酬を二重に配りません。保存不可の環境では、そのページ内だけの進行です。


### 現在のモードと切り替え

通常画面の水槽上、画面いっぱいの水槽では左上の「現在の操作」に、実際の操作モードを表示します。「切り替え」で、つつく・なでる・一緒に泳ぐ・脳を見るを直接選べます。選択中はチェック表示。音あそびの開始・終了、ノート内のなでる／追従チェック、脳を見るボタンからの変更にも表示が追従します。追従とクリック操作をノートで組み合わせた場合は、現在のクリック操作と追従オン／オフを別々に表示します。休止中は切り替えメニューにも休止と再開方法を表示します。

「遊びを選ぶ」のカードは設定ページを開きます。水槽の操作を開始するボタンとは役割が違うため、ノート内に現在の操作と開始手順を表示しました。ハエ脳／プログラムのプリセットは選択中の状態を強調し、日本語で比率と反映済みの表示、切り替え時の通知を出します。脳を見る操作は演奏を終了して切り替えます。


### 育つ水槽とおるすばんの遊び

遊びノートの「おるすばん」から次の遊びができます。水槽モードでは右上にも現在の水槽名とお便りのボタンを表示します。

- 孵化した魚は1時間で幼魚、4時間で大人になり、見た目も大きくなります。名前・性格・仲良し度を保存します。餌やなでる操作に反応し、通常のクリックでは逃げます。育成魚の動きは観賞用のプログラム制御です。
- 元からいる魚と育成魚にはお気に入りの海藻や飾りができ、ときどき近くで休みます。餌・敵・マウスへの反応を優先します。
- カニのお店番は1時間に貝殻2個を集めます。15分ごとにあいさつでき、仲良し度5で4個、15で6個になります。100個まで預かり、受け取りは一度だけ反映します。
- 浅瀬と星砂の探検を受け取ると6時間の珊瑚の迷路、さらに8時間のオーロラの海が開きます。発見した場所と訪問回数は地図に残ります。
- 約20%の卵から真珠・夕焼け・ミント色の魚が生まれます。5種×4色の図鑑に発見を記録します。
- 成長・お気に入り・探検・30分ごとの思い出がお魚の名前付きのお便りになります。最新30通を保存し、既読状態も残ります。
- Lv.2で夕焼け、Lv.3で星夜の水槽を解放します。水槽名と模様替えはそれぞれ保存され、育成魚は引っ越せます。元からの魚は最初の水槽に住みます。育成魚と卵の合計は全水槽で12匹、大人の魚は200匹までのおやすみホテルで休ませて、空きがあれば戻せます。名前・色は失われません。

閉じている間の進行は既存の上限と同じ最大8時間です。世話をしないことによる病気や死亡はありません。以前のセーブは引き継ぎ、既存の探検写真から地図も復元します。


### 操作を見失わないための案内

現在の水槽名と住んでいる魚の数を表示し、新しい空の水槽では元の魚の居場所、「はじめの水槽へ戻る」「育てた魚を引っ越す」を案内します。通常画面では水槽上に案内を置き、魚のタップを妨げません。「おるすばん」には水槽・育てた魚・探検・地図・色違い・お便りへのショートカットがあります。

育成魚のカードには住む場所と、選ぶとすぐ引っ越すことを明示します。名前・引っ越し・ホテル・カニの操作結果は画面上に通知します。育成魚と最初からいる魚の名前を付ける場所、模様替えが現在の水槽だけに反映されること、レベルアップに必要な時間と図鑑項目の残り、ホテルの満員や空きも案内します。設定の魚数は最初の水槽の魚に対する設定です。泳ぎのやり直しではノートと育成記録を残します。

放置画面の上部に、今受け取れる貝殻の合計・内訳、次の卵または孵化、開花までの時間、次の水槽レベルの条件を表示します。一括受け取りは貝殻ひろい・開花済みの海藻・カニのお店・訪問中の妖精・帰還済みの探検が対象で、未完成の育成を進めたり消費したりしません。図鑑のヒントと模様替えへその場から移動できます。


## 俊敏な泳ぎ

つついた場所から離れる方向に切り返し、約0.5秒の短いダッシュで逃げます。近い敵にも反応し、ダッシュ後は普段の速度へ戻ります。連続入力でも最高速度は360に制限し、最大8ピクセルずつ衝突を確認します。テトラなどの小さな魚は素早く、フグは加速と速度を控えめにしました。

落ち着いている近くの魚同士は時々、約1.35秒の追いかけっこをします。餌・敵・クリックの驚き・マウスへの追従を優先し、探検中の魚は参加しません。100% Fly BrainではこのProgramの追いかけっこを始めず、混合する運動出力の比率は維持します。育てた魚もクリック時に位置が飛ばず、短い移動で逃げます。
